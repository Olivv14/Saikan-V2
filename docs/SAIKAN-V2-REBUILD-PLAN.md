# Saikan V2 Rebuild Plan

This repository implements the Rafa-reviewed Saikan v2 direction.

- New independent GitHub repository: `Olivv14/Saikan-V2`.
- Current Saikan project is read-only reference.
- Mobile visual identity from the current site is preserved.
- Tablet and desktop use intentional wider responsive compositions instead of the old centered phone-frame layout.
- Stack: React, TypeScript, Vite, React Router, Tailwind CSS v4, Swiper, Lucide React, Supabase, Vitest, React Testing Library, and Playwright.
- No legacy `home-legacy.css`, `home-layout.css`, or page-wide override CSS copied.

## Current checkpoint

Initial implementation includes app shell, routes, typed content, shared primitives, contact separation, responsive styling, unit tests, and Playwright scaffolding.
